# 🍽️ Casa do Cais

A modern restaurant website inspired by traditional Portuguese dining and Lisbon's riverside atmosphere.

The website presents the restaurant, its story, space, menu, location and contact information, while providing an online table reservation flow with email confirmation.

## ✨ Features

* **Restaurant Presentation** — Introduction to the restaurant, its history and concept.
* **Specialties** — Dedicated section for dishes, descriptions and prices.
* **Restaurant Space** — Information about the dining room, wine cellar and outdoor patio.
* **Gallery** — Visual presentation of the restaurant, food and surrounding area.
* **Location** — Address, transport information and embedded map.
* **Opening Hours** — Weekly opening hours displayed clearly.
* **Online Reservations** — Reservation form for customers to submit their booking details.
* **Email Confirmation** — Customers receive an email confirming their reservation.
* **Responsive Design** — Adapted for desktop, tablet and mobile screens.
* **Custom Visual Identity** — Editorial design inspired by Portuguese architecture, traditional restaurants and riverside Lisbon.

## 🛠️ Technologies

* **HTML5** — Semantic structure and content
* **CSS3** — Layout, responsive design, animations and visual styling
* **JavaScript** — Interactions, form behaviour and dynamic functionality
* **Email Service** — Reservation confirmation emails
* **Google Maps** — Embedded location map
* **Vercel** — Deployment and hosting

## 🎨 Design

Casa do Cais uses a warm editorial aesthetic inspired by traditional Portuguese restaurants and Lisbon's historic architecture.

The visual design combines:

* Serif typography for a traditional editorial feel
* Warm, neutral tones
* Portuguese-inspired visual elements
* Large food and interior photography
* Structured editorial layouts
* Responsive navigation
* Subtle transitions and animations
* Clear visual hierarchy
* Consistent spacing and typography

The goal was to create a website that feels **established, authentic and inviting**, while keeping the interface modern and easy to navigate.

## 📅 Reservation Flow

The website includes an online reservation experience where visitors can submit their reservation details and receive an email confirmation.

The current project **does not include a restaurant-side reservation management system or database for managing availability**. The reservation flow is focused on the customer-facing experience and email confirmation.

## ♿ Accessibility

Accessibility was considered throughout the interface to make the website easier to navigate and understand.

* Semantic HTML
* Descriptive text for images
* Accessible navigation
* Clearly labelled form fields
* Readable typography
* Responsive layouts
* Structured content hierarchy
* Keyboard-friendly interactive elements
